- Start from search intent: what the searcher wants to do (learn, compare, buy, find a place). One page per
  intent; do not stuff keywords.
- Keyword list: main term, long-tail questions ("kuaför randevu sistemi nasıl kurulur"), local terms. Without a
  keyword tool, say the volumes are unknown instead of inventing them.
- Page basics: unique title (≤60 chars), meta description (50-160), one h1, logical h2/h3, descriptive URLs,
  alt text, internal links, fast load, mobile first, structured data (launch_seo_audit checks these).
- Content that deserves to rank: answers the question in the first paragraph, then depth, examples, steps,
  a table or checklist, original data or screenshots. Date and author shown.
- Technical: sitemap.xml, robots.txt, canonical URLs, no duplicate pages, hreflang for TR/EN.
- Never generate thin mass pages or hidden text; it gets penalised.
