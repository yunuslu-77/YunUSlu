- Write the storyline first: the one sentence the audience should remember, then 5-12 slide titles that
  are full-sentence messages. Read only the titles - they should tell the story.
- One idea per slide; few words; large type (≥ 24 pt); visuals that prove the message (chart, screenshot,
  diagram - render_html / chart / diagram tools).
- Numbers come from computations; sources in small print.
- Speaker notes carry the details.
- Build the real file (office_pptx_create) or an HTML deck, then render every slide to PNG and look at it:
  overflowing text, low contrast and misaligned items are bugs.
