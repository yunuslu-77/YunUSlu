- Formlar: görünür etiketler, sade dilde satır içi doğrulama mesajları, gönderirken pasif buton, başarı
  bildirimi, Enter ile gönderme.
- Erişilebilirlik: anlamsal HTML (button, nav, main, label), alt metin, görünür odak, kontrast ≥ 4.5:1,
  mobilde dokunma alanı ≥ 44px, `lang` özelliği.
- Duyarlı tasarım: önce mobil; 375px, 768px ve 1280px genişlikleri kontrol et; yatay kaydırma olmasın.
- Tutarlılık: tek boşluk ölçeği, tek yazı ölçeği, tek ana renk; bileşenleri yeniden kullan.
- Türkçe metin: uzun kelimelerin ("Kullanıcılarımızdan") düzeni bozmadığını kontrol et; İ/ı büyük-küçük harf
  dönüşümünü doğru yap (`toLocaleUpperCase('tr-TR')`).
- Sadece kodu okuyarak değil, sayfayı screen_open ile açıp kullanarak doğrula.
